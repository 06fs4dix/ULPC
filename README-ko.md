# Modified Universal LPC Spritesheet Character Generator

이 프로젝트는 [Universal-LPC-Spritesheet-Character-Generator](https://liberatedpixelcup.github.io/Universal-LPC-Spritesheet-Character-Generator)를 포크(Fork)하여 특정 목적에 맞게 수정 및 개선한 프로젝트입니다. 기본적인 작동 방식과 상세한 이력은 원본 사이트를 참조해 주시기 바랍니다.

## 🛠 주요 변경사항 (Key Changes)

### 1. 저장 방식 및 파일 네이밍 규칙 변경
기존의 복잡한 JSON 대조 방식에서 **직관적인 폴더 및 파일 네이밍 방식**으로 교체되었습니다. 파일명 자체에 메타데이터를 포함함으로써, JSON 데이터와 실제 이미지 위치를 일일이 대조해야 했던 번거로움을 간소화했습니다.

* **네이밍 규칙:**
    `[프로젝트명]-[최상위 파트]-p[하위 파트]...n-a[애니메이션 이름]-z[깊이]-[팔레트 컬러]_[사이즈]_[프레임]_[방향].png`
* **장점:**
    * 파일명만으로 해당 이미지의 속성을 즉시 파악 가능합니다.
    * 프로젝트명이 접두사로 포함되어 다른 에셋들과 이미지 정보를 통합하거나 관리하기에 매우 용이합니다.

### 2. 가변 애니메이션 프레임 규격 통일
기존 ULPC 프로젝트의 가변 프레임 및 가변 사이즈 방식을 개선하여 **프레임 규격을 통일**했습니다.

* **문제 해결:** 기존의 아이들(Idle, 0-0-1), 워크(Walk, 1-2-3...)와 같이 프레임이 불규칙하게 반복되거나 비어있는 경우, 파싱 시 하드코딩이 필요했던 문제를 해결했습니다.
* **수정 사항:** 프레임을 복사 삽입하거나 삭제하여 모든 애니메이션이 일정한 규칙을 따르도록 처리했습니다.
* **최적화:** 최대 프레임 사이즈를 기준으로 이미지를 구성하므로 호환성 문제가 없으며, 특정 주기로 반복되는 애니메이션(`000111222` 등)은 코드 내 애니메이션 스피드 조정을 통해 유연하게 처리할 수 있습니다.

### 3. 뷰어(Viewer) 최신화 및 경량화
외부 라이브러리 의존성을 최소화하고 최신 웹 표준에 맞춰 UI를 개선했습니다.

* **UI 프레임워크:** Bootstrap 5 버전으로 통합 및 업그레이드되었습니다.
* **커스터마이징:** 새롭게 변경된 파일 형식 및 구조에 맞춰 뷰어 로직을 전면 수정했습니다.

### 4. JSON 데이터 구조 개선
추출되는 JSON 형식 내에 파일 구조와 선택된 팔레트 정보를 직접 포함하도록 변경했습니다.

* **독립성 확보:** 별도의 상수로 정의된 정보 없이도, 추출된 JSON 데이터만으로 에셋을 즉시 사용할 수 있습니다.
* **유연성:** 팔레트 정보가 포함되어 있어 런타임에서 동적인 색상 변경 및 처리가 더욱 간편해졌습니다.
